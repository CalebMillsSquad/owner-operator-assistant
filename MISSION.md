# Active Mission

## Mission Title

Mills Trucking External-Testing Pilot

Mission status: In progress.

## Objective

Provide one explicitly invited Mills Trucking owner-operator a protected, isolated Vercel Preview of the Assistant Command Center and Freight Intelligence workflows using only realistic fictional data.

## Acceptance Criteria

- Dedicated pilot branch, Vercel project, Preview deployment, PostgreSQL database, and workspace.
- No local SQLite database, uploads, receipts, documents, or private records copied.
- Persistent `Mills Trucking Pilot - Test Data Only` banner and pilot-only company welcome profile.
- Invitation-only `TESTER` and `OWNER` authentication with all private access scoped to the pilot workspace.
- Built-in route/category/description/viewport feedback capture; screenshots disabled until isolated object storage is approved.
- Owner-only transactional reset restores the complete reviewed fictional workflow seed.
- Test and security runbooks cover workflow, feedback, isolation, credentials, reset, and teardown.
- Prisma validation, migration review, lint, typecheck, tests, local and pilot production builds, responsive browser checks, keyboard acceptance, and private-route checks pass.
- A protected Preview URL and private credential-delivery procedure are ready for one tester.

## External Gate

The Founder must provide or approve a separate free-tier PostgreSQL pilot database, separate Vercel Pilot project/environment values, the invited tester email, and the approved Mills Trucking vision graphic. No paid service or production deployment is authorized.
